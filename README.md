# Recess Linux

A live Linux desktop for families and classrooms: Fedora with KDE Plasma,
Firefox, GCompris, Tux Paint and LibreOffice, under a bright sky of toy
blocks. Start it from a USB stick and nothing on the computer changes.

Made with [linuxlive](https://linuxlive.com) from the template
[Eric-Ness/linuxlive-distro](https://github.com/Eric-Ness/linuxlive-distro).
Everything about it is in [`linuxlive.yaml`](linuxlive.yaml); GitHub Actions
builds and boot-tests the ISO on every push (see the Actions tab).
